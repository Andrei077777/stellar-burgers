## Этапы работы:

1. Разверните проект и ознакомьтесь с кодом. Все необходимые вам компоненты уже созданы и лежат в папке `src/components`

2. Настройте роутинг.

3. Напишите функционал запросов данных с сервера, используя `Redux` и глобальный `store`. Сами "ручки" уже прописаны и лежат в `utils/burger-api.ts`

4. Настройте авторизацию и создайте защищённые роуты.

## Важно:

Для корректной работы запросов к серверу необходимо добавить переменную BURGER_API_URL в окружение. Сама ссылка находится в файле `.env.example`.

## Тесты

В проект добавлены юнит-тесты на Jest и интеграционные тесты на Playwright.

### Jest

Тесты редьюсеров лежат в папке `src/services/slices/__tests__`.

- `npm test` — запуск юнит-тестов;
- `npm run test:watch` — запуск в режиме наблюдения;
- `npm run test:coverage` — запуск с отчётом о покрытии (сводка в консоли, подробный отчёт в `coverage/lcov-report/index.html`).

### Playwright

Тесты страницы конструктора лежат в файле `tests/constructor.pl.tsx`, моковые ответы бэкенда — в папке `tests/hars`.
Перед первым запуском нужно скачать браузер:

```
npx playwright install chromium
```

Если скачать браузер не удалось, тесты автоматически используют установленный в системе Google Chrome.

- `npm run test:e2e` — запуск интеграционных тестов (dev-сервер на порту 4000 поднимается автоматически);
- `npm run test:e2e:ui` — запуск в интерактивном режиме;
- `npm run test:e2e:report` — открыть HTML-отчёт последнего запуска.
